## Provenance of the archived subset shipped in this repository

`crates/domains/data/propbank/propbank-3.4.0.propbank` is a deterministic
directory archive (see `decoders::file_collection`) of every real frame
`.xml` file under the official `frames/` directory at tag `v3.4.0`
(commit `4087fa9ab5c40907c34ff91a56acc2cab1670145`), excluding the three
non-frame entries the directory also carries (`.gitignore`, `README.txt`,
`frameset.dtd`) -- 7,565 of 7,568 tree entries, verified 2026-07-13 via
`gh api repos/propbank/propbank-frames/git/trees/<sha>:frames`. Every
archived file's bytes are carried verbatim (no field extraction, no
reweighting, no editorial interpretation of the source data) -- see
`regenerate.rs`'s module doc for the exact archiving step and its
literature/URL citations.

Per the ShareAlike term, this derived archive is distributed under the
same CC-BY-SA 4.0 license as the original.
