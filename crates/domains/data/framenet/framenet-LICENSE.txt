## Provenance of the extracted subset shipped in this repository

`crates/domains/data/framenet/framenet-1.7.tsv` is NOT the full FrameNet
release (855,026,962 bytes uncompressed, dominated by the annotated-sentence
corpus). It is a mechanical extraction: for each of the ~13,574 lexical-unit
XML files, only the root `<lexUnit POS="..." name="..." frame="...">` start
tag's three attributes (lemma, part of speech, evoked frame) are kept —
never the embedded annotated-sentence corpus each file also carries; for
`frRelation.xml`, only each `<frameRelation subFrameName="..."
superFrameName="...">` pairing (never the nested frame-element-level
mappings) is kept. A pure format-conversion, never a reweighting,
re-ranking, or editorial interpretation of the source data. See
`regenerate.rs`'s module doc for the exact extraction and its citations.

Per CC-BY-3.0 (no ShareAlike requirement, unlike ConceptNet's CC-BY-SA-4.0),
this derived extraction may be distributed under this project's own terms,
provided the attribution above is preserved.
