## Provenance of the extracted subset shipped in this repository

`crates/domains/data/sumo/sumo-wordnetmappings-30.tsv` is NOT a copy of
the raw WordNetMappings30-*.txt files (~22 MB across the four files,
each a full annotated Princeton WordNet 3.0 `data.*` record per line —
synset offset, lexicographer file number, part of speech, member words,
pointers, and gloss, none of which this project needs). It is a
mechanical extraction + offline resolution: for each `&%<term><suffix>`
annotation on each data line, the synset's WordNet SENSE KEY is
reconstructed from that line's own member-word/lex_id/lex_filenum/
ss_type fields and resolved to this project's loaded Open English
WordNet 2025 `ConceptId`; only `concept_value<TAB>term<TAB>relation_code`
rows survive. No WordNet gloss, pointer, or member-word text is
retained. See `regenerate.rs`'s module doc for the exact extraction and
its citations.
